## Project Overview

Freelancers and small agencies often suffer from overwhelming enterpeise resource planning tools. Chronos aimed to be single-mindedly focused on starting timers, logging hours, and generating invoices fast.

## Implementation Details

We utilized the classic T3 stack style architecture for this build.

1.  **Next.js Server Actions:** Utilizing the newest React features natively built into framework to bypass redundant REST API layers for fast, secure database interactions.
2.  **Schema First Database:** Using Prisma schema as our source of truth, automating database migrations and creating heavily typed client integration code.
3.  **Stripe Billing:** Seamless integration to allow contractors to bill their clients straight from generated project reports.

## Outcome

Achieved 20k monthly active users generating over $2M in tracked invoices within the first year of release.
