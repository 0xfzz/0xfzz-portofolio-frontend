# 0xfzz Portfolio Frontend

This repository contains the codebase for my personal website: [**www.0xfzz.my.id**](https://www.0xfzz.my.id)

## Overview

This is the frontend layer of my portfolio project ecosystem. It dynamically fetches content from a dedicated content repository.

## Project Ecosystem

This project is part of a larger ecosystem:

- **Live Site**: [0xfzz.my.id](https://www.0xfzz.my.id)
- **Content Source**: [0xfzz-portofolio-content](https://github.com/0xfzz/0xfzz-portofolio-content) — Centralized markdown files and assets.
- **Frontend Portfolio**: [0xfzz-portofolio-frontend](https://github.com/0xfzz/0xfzz-portofolio-frontend) — This repository (Next.js App).
- **CMS Studio**: [0xfzz-portofolio-studio](https://github.com/0xfzz/0xfzz-portofolio-studio) — Custom management interface for project and blog content.
